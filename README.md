🏀 NBA Scoreboard 2.0

A simple and responsive NBA Scoreboard web application that displays live or mock NBA game scores in an easy-to-read format. Built to practice frontend development, API integration, and clean UI design.

📌 Features

🏀 Displays NBA teams and scores

⏱️ Shows game status (Live, Upcoming, Finished)

📊 Clean and responsive scoreboard layout

🌐 Ready for API integration (live data or mock data)

💻 Works on desktop and mobile screens

🛠️ Built With

HTML5

CSS3

JavaScript (ES6)

(Optional) NBA API / Sports API

(Optional) GitHub Pages for deployment
